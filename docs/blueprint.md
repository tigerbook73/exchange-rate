# 技术方案

记录容易改错的数据与 API 规则；操作见 [README](../README.md)，开发流程见 [AGENTS](../AGENTS.md)。这是私人应用，保持现有简单架构，不追求高可用；Cloudflare Free 下的 CPU 效率和资源用量仍是设计约束。

## 架构与数据源

```text
每分钟 Cron → collector → 工商银行 JSON → D1
部署前 Node 脚本 → 快易理财历史 HTML → D1
浏览器 / PWA → 网站 Worker（只读 API + 静态资源）→ D1
    └─ IndexedDB / Serwist：离线副本
```

- 网站使用 Vite + React + Cloudflare Vite 插件，两个 Worker 均不依赖 Node 兼容层。历史校准独立在 Node 运行，Cron 不导入 HTML 解析依赖。前端不导入服务端实现。
- 现价：POST `http://papi.icbc.com.cn/exchanges/ns/getLatest`，空 body，保留实现中的 Content-Type / Referer / User-Agent。取唯一 `AUD` / `029` 的 `foreignSell`（人民币 / 100 澳元），按十进制舍入转为每澳元万分之一单位整数。完整日期与秒级时间按 UTC+8 解释；校验失败保留旧报价，不改用现金价或其他源。当前 HTTP 入口来自既有请求，HTTPS 曾有 TLS 问题，不关闭证书验证绕过。
- 历史：`https://www.kylc.com/huilv/d-icbc-aud.html?datefrom=YYYY-MM-DD`，用 `cheerio/slim` 读逐日表，初始化回溯 365 天。请求超时 8 秒；JSON 上限 64KiB，历史 HTML 上限 1MiB。
- 旧现价网页解析器、测试、fixture 和依赖继续保留，等新 API 稳定后再决定；当前不调用或自动回退。旧源缺年份的时间以北京时间当前年为基准，12 月 / 1 月跨界调整年份。

## CPU 与资源开销

- 优先让现有热路径少做工作：轻量 JSON 现价解析、索引查询、增量同步、批量写入和有界清理；减少重复序列化 / 日期格式化，不为提高可用性增加常驻诊断、密集重试或额外服务。
- 历史 HTML 解析放在部署前 Node 脚本，静态资源交给 Cloudflare Assets；不因用户少就放宽每次 Cron / API 的 CPU 成本。保持数据正确性，不以减少采样或丢弃历史来代替优化。
- 影响热路径、打包或运行时依赖时按需验证性能；本地对比用于发现回退，线上 collector / 网站 CPU 和 D1 用量用于确认免费计划适配。请求总耗时、包大小或一次成功都不能证明 CPU 达标，缓存响应头也不能证明实际命中；当前限额在需要验收时核对，不把数值写死为长期承诺。

## 采样、历史与保留

- 业务日期统一北京时间。采样分钟以实际发起时间 `requestedAt` 截断计算，不以 Cron 计划时间、响应完成时间或源站发布时间替代；报价发布时间独立保存。
- 每分钟采集，整 5 分钟保存固定点，其余分钟覆盖唯一临时点；固定边界处理后清除之前的临时点。漏触发的旧边界在覆盖真实成功状态前处理。
- 固定点 T 失败时只可取 `[T−5 分钟,T]` 内最近真实成功值，保留来源分钟 / 请求时间及 `isFallback`。无来源则缺失，不用未来值倒填，也不把回退点继续当真实来源。跨日旧报价不能作为新一天真实历史。
- 每日暂定值来自当天真实报价；部署前或显式回填时用历史源校准，只接收今天之前的记录。历史使用独立游标，起点为最后确认日期与最早未校准暂定日期中的较早者；源站省略某日不覆盖已有真实 / 暂定值。
- 缺日补到昨天，引用此前最近真实 / 暂定记录，标记 `carried-forward` / `carriedFromDate`。不连续引用填补值、不向前倒填、不补今天、不硬编码周末；沿用不代表当天没有报价。每日首次分钟提交补尾部缺日，`dailyFilledThrough` 随原子批次推进；显式修复也可补内部缺日，历史修订后重算沿用值。
- 固定点保留今天与前两天，临时点最多一个；每日历史长期保留，UI 默认一年；同步变更保留 3 天，旧 D1 诊断保留 30 天。每 15 分钟有界物理清理，查询先按逻辑范围过滤；清理失败不回滚已成功采集，不删除每日历史。
- 历史校准只在部署前或显式命令执行；长期不部署可能延后历史修正，这是当前取舍。演示数据不与真实数据混用。

## D1 一致性

`collection_state` 保存数据集身份、revision、游标和最近采集状态；`intraday_points` 保存固定点，`daily_rates` 保存每日值，`sync_changes` 保存实体变更及删除标记。`collection_runs` 仅保留旧诊断，新任务用结构化日志。

- 正常分钟轮次一次状态读取、一次 D1 batch。按分钟幂等；revision 条件和随机 `write_id` 确认本批获准写入，状态、实体、变更标记原子提交。冲突可跳过，不加租约锁或密集重试。
- 源站价格与发布时间都未变时不重复写每日值；报价时间倒退不覆盖可信最新值。历史抓取后重新读取状态再条件提交，避免覆盖并发采集。
- 批量点使用 `json_each`；查询通过单条 SQL 保持数据与游标同一快照。分时查询只按日期索引读对应点及状态。
- migrations 是新库初始化及升级依据，不能因已在生产执行就删除。结构代次 `schema_version=1` 与 API schema、报价 revision 不同；结构和 `write_id` 检查在显式操作 / 部署前执行，不逐请求检查。

## API 与客户端同步

所有 API 只读 D1，不抓源站。只支持 GET，其他方法 405；未知路径（含已退役 today / history）返回 JSON 404，不进入 SPA 回退。

| API                                                | 用途                                                   |
| -------------------------------------------------- | ------------------------------------------------------ |
| `/api/sync?schema=1`                               | 快照：最近一年每日值、三日固定点、临时点及状态         |
| `/api/sync?schema=1&cursor=<datasetId>.<revision>` | 增量：变更实体的当前值和删除标记，不回放每分钟临时价格 |
| `/api/intraday?date=YYYY-MM-DD`                    | 保留期内指定日分时，过期返回 410                       |

- 响应携带 schema、datasetId、revision、cursor、生成时间、保留 / 历史窗口及状态；字段定义以 `src/lib/contracts/server-types.ts` 为准。
- 失效游标 / 数据集变化返回 409 `resetRequired`，客户端重新取有限快照；未初始化或数据库错误返回 503。API 版本不匹配返回 426 `client_upgrade_required` 和目标 schema。错误响应 `no-store`，正常响应共享缓存 15 秒、允许额外 15 秒陈旧；完整游标参与缓存键，实际 CDN 命中另看运行表现。
- 页面可见且在线时每 60 秒同步，打开、唤醒、恢复网络和刷新立即尝试；同时只运行一次，离线和隐藏停止轮询。请求失败保留已有值。
- IndexedDB `fx-cache` v2 保留旧 `rates`，增加 `points` / `server`；先显示已有缓存。实体、窗口清理及新游标在同一事务提交；拒绝旧版本、同版本更旧快照和不同数据集的 delta。
- 协议不兼容时在线可见客户端自动刷新一次，sessionStorage 防循环；仍不兼容则保留数据并提示重开。仅取得合法兼容快照后原子重建本地副本；只清旧 API 响应缓存，保留新版程序资源。旧标签页不能将高 schema 缓存写回低版本。报价 revision 变化不触发清库 / 页面升级；数据集变化可直接用快照重建，不反复刷新。
- 离线不会主动擦除数据；成功同步后才按窗口清理固定点。正常快照可以替换本地每日窗口，服务端更早历史继续保留。时间范围删除 / 格式化复用日期边界和格式化器，避免逐点重复计算。

## PWA 与显示

- Serwist 使用 `@serwist/vite` / `defaultCache`；保持 `/sw.js` 和根 scope，预缓存排除 `/_headers` / `/_redirects`。开发模式不注册。API NetworkFirst 的离线缓存也可能返回 200，不能当作刚联网成功；首次未在线加载不保证离线使用。
- 只跟随系统亮暗主题，字体自托管。HTML 在应用资源到达前设置主题和底色；浏览器主题色随系统，manifest 保持静态色。
- 默认 30 天每日历史；1 日看分时，其余为 7 天、90 天、半年、一年。当天无有效新报价时显示最近有效报价日并标日期；有效日超保留期时卡片仍显示旧价，分时提示过期。
- 分时裁掉首尾空段，中间缺口仅在显示层沿用前值并标来源；“昨天”参考线取前一有效日末值，tooltip 保留实际日期。不能凭参考线或今天观察到的旧报价伪造有效日走势，显示层沿用不写入数据库。
- 旧日报价显示“今天无更新”；同日报价时间落后最近检查至少 5 分钟显示“当前无更新”，不以价格是否变化判断。离线、等待数据和同步错误保留行内提示，刷新时保留结构和值，数字旁显示旋转图标。
- 范围选择器单行滚动；交互竖线使用独立覆盖元素，保留 tooltip 动画。返回前台主动 resize，避免图表旁插入占位说明造成抖动。页脚保留快易理财与工商银行来源链接。
